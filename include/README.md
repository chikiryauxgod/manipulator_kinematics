# Публичный API

Заголовки в `manipulator/` описывают модель, преобразования, прямую и обратную кинематику. Память для модели, результатов и рабочего буфера предоставляет вызывающий код; длины задаются в метрах, углы — в радианах.

Описание функций и порядка вызовов — в [руководстве C API](../docs/c-api.md).
