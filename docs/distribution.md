# Подготовка первой поставки

Версия разработки 0.1.0. Этот документ описывает состав пакета и оставшиеся условия поставки; опубликованного релиза пока нет.

## Состав пакета CMake

`cmake --install` устанавливает только статическую библиотеку выбранного профиля, публичные заголовки, сгенерированный config.h и CMake package config/targets. Текст MIT LICENSE устанавливается в CMAKE_INSTALL_DOCDIR (по умолчанию share/doc/manipulator). В пакет не входят GoogleTest, pytest, Python, тестовые бинарники, embedded startup или PDF-пособие. Математический runtime предоставляет целевой toolchain; он не встраивается в архив библиотеки при её сборке.

Для каждого профиля нужен отдельный install prefix:

```sh
cmake -S . -B build-release-double -DCMAKE_BUILD_TYPE=Release -DMANIPULATOR_REAL_TYPE=double
cmake --build build-release-double
cmake --install build-release-double --prefix "$PWD/install-double"
cmake -S . -B build-release-float -DCMAKE_BUILD_TYPE=Release -DMANIPULATOR_REAL_TYPE=float
cmake --build build-release-float
cmake --install build-release-float --prefix "$PWD/install-float"
```

У профилей различаются имена архивов и ABI-символы, но пути config.h и импортируемое имя target одинаковы. Установка двух профилей в один prefix перезапишет конфигурацию; совместная установка пока не поддерживается. Пакет переносим между каталогами на совместимой платформе, но не между произвольными архитектурами или ABI компиляторов.

До версии 1.0 CMake принимает запрос версии только с совпадающими major/minor и доступным patch. Например, пакет 0.1.0 подходит для `find_package(manipulator 0.1 CONFIG REQUIRED)`, но отклоняет запросы 0.0, 0.1.1 и 1.0. Разные minor-версии API в период разработки не объявляются совместимыми автоматически.

Тест `test_relocated_install_and_external_consumers` проверяет оба профиля и стандартные/нестандартные каталоги: собирает отдельную копию ядра, устанавливает и перемещает пакет, удаляет исходники и build-каталог библиотеки, затем собирает и выполняет внешние C/C++ приложения. Все пути в этом сценарии содержат пробелы.

## Условия первой поставки

MIT выбрана с разрешения владельца проекта. Условия сторонних материалов описаны отдельно; собственная лицензия их не заменяет.

Обязательные jobs [удалённого CI](https://github.com/chikiryauxgod/manipulator_kinematics/actions/runs/38043984848) для commit 15c4d8f прошли; текст MIT включён в пакет. До объявления отдельного релиза остаются утверждение его состава и публикация выбранных артефактов. Поставка бинарного пакета должна указывать профиль, архитектуру, compiler/runtime и идентификатор исходного commit. Результаты локальной проверки приведены в [валидации](validation.md).

Пособие ИТМО уже присутствует в историческом репозитории, но разрешение на его внешнее распространение не установлено. Оно не входит в устанавливаемый CMake-пакет. Если готовится отдельный исходный архив, решение о включении PDF необходимо принять отдельно от лицензии собственного кода. Информация о сторонних материалах и тестовых зависимостях — в [перечне компонентов](third-party.md).

Реальный микроконтроллер ещё не выбран. Проверка Cortex-M4 в QEMU подтверждает cross-линковку и выполнение; измерения частоты вызовов и WCET на плате требуют отдельного аппаратного окружения и не входят в подтверждённые характеристики пакета.
