Задание пользователя требует конечную точку. Полная постановка ОЗК в пособии включает ещё и ориентацию, но в проекте решается только p(q) = p_target. Матрица ориентации остаётся частью FK; извлечение углов Эйлера и ошибка ориентации для поиска не нужны. При использовании внешнего решателя его позиционный режим должен быть явным: единичная ориентация в целевой матрице без отключения её ограничения меняет задачу.

## Замечания к формулам

### Линейная часть якобиана: перестановка типов на с. 20

На странице PDF 21 визуально проверено: выражение z_(i-1) подписано как вращательное сочленение, а векторное произведение — как поступательное. Это перестановка. Для вращательного сустава и точки инструмента используются:

```text
J_v,i = z_(i-1) × (p_tool - o_(i-1))
J_ω,i = z_(i-1)
```

Для поступательного сустава, если он появится позднее:

```text
J_v,i = z_(i-1)
J_ω,i = 0
```

Основание исправления — определение J_v,i = ∂p/∂q_i на той же странице и итоговая матрица вращательного манипулятора на с. 21. Для вращения дифференциал положения точки равен векторному произведению оси на плечо; для переноса — самой оси. Это математическая проверка, а не изменение по предпочтению реализации.

Простейший контроль: вращение вокруг z точки p = (L, 0, 0) при q = 0 даёт производную (0, L, 0). Формула z дала бы (0, 0, 1), что неверно. Для всех столбцов реализуемого якобиана предусматривается проверка:

```text
J_fd[:, i] = (p(q + h e_i) - p(q - h e_i)) / (2 h)
```

Начальные настройки проверки для демонстрационных размеров: h = 1e-6 рад, абсолютный допуск компоненты 1e-7 м/рад, относительный 1e-5. Это проектные значения, которые проверяются при реализации; использовать несколько h для диагностики ошибки округления. Тесты включают ненулевые theta_offset, базу и инструмент.

### Размерность и псевдообратная

В пособии обсуждается полный J размером 6×n. Для текущей цели используется J_v размером 3×n, поэтому классификация только по n < 6, n = 6, n > 6 не переносится на неё напрямую. Даже при n = 6 позиционный якобиан прямоугольный. Формула Jᵀ(JJᵀ)^−1 требует полного строкового ранга и не применяется буквально в сингулярности. Выбранная DLS-регуляризация описана в архитектуре и является дополнением проекта, не требованием пособия.

### DH и геометрия

На с. 12 уже есть нулевые a_i/d_i и отрицательные alpha_i. DH-параметры описывают смещения и вращения координатных систем, поэтому правило «все длины строго положительны» нельзя применять к каждому параметру DH. Геометрические размеры выбранной конструкции проверяются отдельно. Стандартный порядок Rz Tz Tx Rx на с. 15 не смешивается с модифицированной DH-конвенцией.

Сферическое запястье и декомпозиция из с. 18 относятся к соответствующей конструкции, а не к любой шестизвенной цепи. В проекте выбран общий численный поиск позиции, допускающий геометрии 3–6R без предположения о сферическом запястье.

## Что не становится частью задания

Пособие содержит отдельные задачи динамики, планирования и управления (§1.2–1.4), лабораторные работы и полный курсовой проект. В приложении А на с. 64 перечислены динамическая модель, планировщик и регулятор; вариант A9 на с. 76 описывает семизвенную систему. Это не совпадает с переданным пользователем заданием на позиционную ОЗК для 3–6 звеньев.

Python и Corke Robotics Toolbox — инструменты пособия. Они не устанавливают обязательный язык этой программы: сохраняется C++17. Форматы отчётов в приложении В относятся к соответствующим лабораторным/курсовым работам; в нашем плане предусмотрено краткое объяснение модели, алгоритма и результатов без автоматического переноса требований к полному отчёту.

Появление PDF не подтверждает необходимость физической сборки. До отдельного указания результатом остаются углы и проверенная позиция математической модели.
