# Динамическая модель и управление

Документ уточняет этапы DYN/PLAN/CTRL из [требований](requirements.md) и [архитектуры](architecture.md). Это математическая симуляция, а не команда реальным приводам.

## Параметры

Для каждого звена задаются масса `m_i`, центр масс `r_i`, тензор инерции `I_i` в локальном кадре. Для привода задаются моторная инерция `Jm_i`, передаточное число `G_i`, вязкое трение `B_i` и кулоново трение `Tc_i`. Углы — рад, скорость — рад/с, ускорение — рад/с², момент — Н·м.

## Уравнение движения

```text
M(q) q_ddot + C(q,q_dot) q_dot + G(q) + F(q_dot) = tau
```

Обратная динамика вычисляет `tau` для заданных `q`, `q_dot`, `q_ddot`. Основной метод — рекурсивный Ньютон–Эйлер; матрица инерции дополнительно получается запуском обратной динамики на базисных ускорениях. Проверяются симметрия `M`, положительная определённость и энергетическая согласованность гравитационной составляющей.

Три обязательных сценария: ненулевые скорость и ускорение, квазистатика (`q_dot != 0`, `q_ddot ≈ 0`) и удержание (`q_dot = 0`, `q_ddot = 0`). Параметры демомодели являются учебными допущениями, если не подтверждены паспортом.

## Планирование

Путь задаётся в пространстве суставов через waypoint-ы. Время добавляется отдельно кубическими полиномами с непрерывными `q`, `q_dot` и `q_ddot`. Для каждого сегмента проверяются `qlim`, `|q_dot| ≤ vmax`, `|q_ddot| ≤ amax`; при нарушении длительность увеличивается или план отклоняется. Минимальная демонстрация содержит не менее трёх waypoint-ов и участок, где скорость меняет знак.

## Регулятор

Базовый регулятор:

```text
e = q_d - q
e_dot = q_dot_d - q_dot
tau = Kp e + Kd e_dot + G(q)
```

Сравнительный вариант computed-torque использует `M`, `C`, `G` и заданные производные траектории. В обоих вариантах моменты насыщаются; физическое достижение цели оценивается по `q`, а не по выданному `tau`. Интегратор состояния принадлежит симулятору объекта, не регулятору.

## Симуляция и отчётность

`PlantSimulator` вычисляет `q_ddot = M(q)⁻¹(τ - Cq_dot - G - F)` и интегрирует состояние фиксированным шагом. Шаг и метод (например, RK4) фиксируются в эксперименте. Регулятор вызывается на каждом шаге или чаще; интерполяция задания не подменяет измерение состояния.

Отчёт содержит графики заданных и фактических `q`, `q_dot`, `q_ddot`, моментов, ошибок по суставам и позиции рабочего органа. Для сравнения указываются RMS и максимальная ошибка, время установления и случаи насыщения.
