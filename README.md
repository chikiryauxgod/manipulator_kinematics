# Библиотека кинематики манипулятора

Текущая задача — переносимая библиотека **прямой кинематики на C11** с настраиваемым числом суставов и без динамического выделения памяти. Исходники пока не реализованы.

Актуальные требования, рабочие решения, границы модулей, C API и критерии проверки описаны в [архитектуре C11-библиотеки](docs/c11-architecture.md).

План тестирования: GoogleTest для модульных проверок C API; pytest для интеграционных проверок потока stdin/stdout отдельного бинарника, собираемого CMake. Тестовая инфраструктура не входит в зависимости ядра для микроконтроллеров.

Архитектура включает защиту линковки профилей float/double, сохранение выходов при ошибках, конкретные критерии численной приёмки и обязательную embedded-проверку Cortex-M4 через cross-сборку и QEMU. Это требования к будущей реализации; результаты этих проверок пока отсутствуют.

Математическая основа — стандартное представление Денавита–Хартенберга и однородные преобразования из [пособия ИТМО](docs/Modelirovanie_i_upravlenie_dvizheniem_robotov_-_ITMO.pdf), §1.1.1, с. 11–16.

Другие документы в docs сохраняют предыдущий проект программы на C++17 с обратной кинематикой, динамикой и управлением. Этот объём не является требованиями текущей библиотеки.
