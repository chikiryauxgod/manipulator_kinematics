# Демонстрационная модель и контрольные конфигурации

Статус: выбранная учебная геометрия для будущей программы. Размеры заданы проектом, а не взяты из паспорта реального робота или рисунка пособия. Модель иллюстрирует стандартное представление Денавита–Хартенберга (§1.1.1 [пособия](Modelirovanie_i_upravlenie_dvizheniem_robotov_-_ITMO.pdf)); не предполагает физической сборки.

## Базовая пространственная цепь 3R

Первый сустав поворачивает конструкцию вокруг вертикальной оси. Следующие два сустава меняют положение плеча и предплечья в поворачивающейся вертикальной плоскости. Первое подвижное звено имеет высоту h, второе и третье — длины L2 и L3. Основание не считается подвижным звеном; инструмент — точка в конце третьего звена, без дополнительной степени свободы.

Параметры: h = 0,10 м, L2 = 0,30 м, L3 = 0,20 м. Мировая система совпадает с базовой, z направлена вверх. T_world_base = I, T_n_tool = I. Суставы идеальные вращательные, без аппаратных пределов и столкновений. Углы q в радианах.

| i | a_i, м | alpha_i, рад | d_i, м | theta_i |
| --- | --- | --- | --- | --- |
| 1 | 0 | π/2 | h | q1 |
| 2 | L2 | 0 | 0 | q2 |
| 3 | L3 | 0 | 0 | q3 |

Для каждой строки A_i = Rz(theta_i) Tz(d_i) Tx(a_i) Rx(alpha_i). Положительные q2 и q3 поднимают соответствующие звенья из горизонтальной нулевой позы. При q = 0 второе и третье звенья направлены вдоль +x; локальные оси z1 и z2 направлены вдоль -y базовой системы. Ненулевая alpha1 обеспечивает пространственное движение.

Независимые формулы позиции, выведенные из этой геометрии:

```text
r = L2 cos(q2) + L3 cos(q2 + q3)
x = cos(q1) r
y = sin(q1) r
z = h + L2 sin(q2) + L3 sin(q2 + q3)
R = Rz(q1) Rx(π/2) Rz(q2 + q3)
```

Эти формулы служат эталоном для DH-FK. Целевое условие использует x/y/z, не R.

| Углы (q1, q2, q3) | Позиция (x, y, z), м |
| --- | --- |
| (0, 0, 0) | (0,50; 0; 0,10) |
| (π/2, 0, 0) | (0; 0,50; 0,10) |
| (0, π/2, 0) | (0; 0; 0,60) |
| (0, 0, π/2) | (0,30; 0; 0,30) |
| (0, 0, π) | (0,10; 0; 0,10) |

## Рабочая область и аналитическая сверка 3R

При указанных идеализациях расстояние до плечевого сустава s = sqrt(x² + y² + (z-h)²) должно удовлетворять |L2-L3| ≤ s ≤ L2+L3, то есть 0,10 ≤ s ≤ 0,50 м. Для этой конкретной модели это необходимое и достаточное условие достижимости точки; оно не распространяется на произвольную DH-цепь.

Встроенная цель предлагается p_target = (0,30; 0; 0,30) м. Известное решение (0, 0, π/2) используется в отчёте, но не подаётся численному решателю как готовое начальное приближение. Точка (0; 0; 0,10) находится во внутренней недостижимой области, (1; 0; 0,10) — вне внешней границы.

Для независимой аналитической сверки можно использовать:

```text
rho = sqrt(x² + y²), u = z-h
c3 = (rho² + u² - L2² - L3²) / (2 L2 L3)
q1 = atan2(y, x)
q3 = ±acos(c3)
q2 = atan2(u, rho) - atan2(L3 sin(q3), L2 + L3 cos(q3))
```

При rho = 0 выбирается q1 = 0: угол основания для осевой цели произволен. Ограничивать c3 интервалом [-1, 1] можно только для малой ошибки округления после проверки достижимости; произвольную внешнюю цель так исправлять нельзя. Пограничная точка принимается как success только по общей проверке ошибки позиции. Это контрольный вывод, не требование писать второй производственный решатель.

## Расширения 4R, 5R, 6R

Сохраняются первые три строки и добавляются последовательные вращательные звенья:

| i | a_i, м | alpha_i, рад | d_i, м | theta_i |
| --- | --- | --- | --- | --- |
| 4 | 0,10 | 0 | 0 | q4 |
| 5 | 0,08 | 0 | 0 | q5 |
| 6 | 0,06 | 0 | 0 | q6 |

Это одна простая семья демонстрационных геометрий с поворотом основания и плоской цепью над ним. Она не изображает все промышленные роботы. Решатель принимает любую проверенную DH-таблицу поддерживаемого размера, но гарантии приёмки подтверждаются только на закреплённых контрольных моделях и целях.

Для этой семьи при n > 3 общий эталон позиции:

```text
phi_i = q2 + ... + q_i
r = sum(i=2..n, a_i cos(phi_i))
z = h + sum(i=2..n, a_i sin(phi_i))
x = r cos(q1), y = r sin(q1)
```

Нулевая поза даёт x = 0,60 / 0,68 / 0,74 м для 4R / 5R / 6R, y = 0, z = h. В тестах нужны и ненулевые конфигурации. Начальные углы численного поиска задаются независимо от тех, по которым получена целевая позиция.

Для произвольной поддержанной DH-модели можно применять только консервативную внешнюю границу: расстояние от начала базы до цели не больше суммы sqrt(a_i² + d_i²) плюс нормы смещения инструмента. Перенос базы сначала исключается преобразованием цели в базовый кадр. Эта граница используется для доказанного отказа с учётом позиционного допуска; её выполнение не доказывает достижимость. Более точная сферическая оболочка 3R выше применима только к соответствующему профилю.

## Дополнительные проверки соглашений

- Для модели с theta_offset сверять результат с моделью без offset и соответственно сдвинутым q.
- При переносе базы на b позиция должна измениться на b; при повороте базы Q позиция и якобиан поворачиваются на Q.
- Смещение инструмента t выражено в последнем кадре: p_tool = p_n + R_n t, а не p_n + t в мировых координатах.
- Проверять RᵀR ≈ I, det(R) ≈ 1 и последнюю строку T = (0, 0, 0, 1), включая ненулевые углы.
- Проверять J_v центральными разностями согласно [разбору теории](theory.md); формулы и тесты не должны копировать опечатку с. 20 пособия.
